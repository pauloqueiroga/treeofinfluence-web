Facilitation

How to plan and run a Tree of Influence session with a group, step by step.

A typical Tree of Influence session is comprised of these steps: Prepare, Seed, Group, Connect, Prioritize, and Decompose, followed by a short Close. The steps stay the same for 5 participants or 30, with varying durations depending on group size.

This section assumes you know the basics. If you have never run a session, read the Quick Start first.

Steps

Prepare
Set up the board and pre-seed it, so the session starts with something to react to.
Seed
Fill the board with many different nodes, without judging any of them.
Group
Cluster related and duplicate nodes, and park what does not fit, without losing any contribution.
Connect
Draw arrows between nodes, and give each node its type as its role becomes clear.
Prioritize
Vote on the nodes that matter most, then read the result together.
Decompose
Break the highest-priority nodes into deep-dive sub-trees, in subgroups or as one group.
Close
End the session with a saved board, a complete legend, and agreed next steps.

Patterns

Origin pattern
Start from a single anchor node and expand outward.
Convergence pattern
Find connections between clusters the group treats as separate.
Challenge pattern
Question a connection that looks too obvious to find the conditions and hidden causes behind it.
Prioritization pattern
Read voting results with the group and discuss the surprises.
Zoom pattern
Treat a single node as its own tree.
Evolution pattern
Walk the previous tree node by node at the start of a new cycle.
