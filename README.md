# Tree of Influence

The Tree of Influence is a diagramming and facilitation technique for mapping how problems, actions, and desired outcomes influence each other.

This repository is where people who use the technique share what they learn. Read the technique itself on the website.

## Contribute

You do not need to write code. Everything happens in plain language:

- **Ran a session?** Share an experience report in Discussions, in the "Experience reports" category.
- **Have an idea?** Post it in the "Ideas" category.
- **Have a question?** Ask in "Q&A."
- **Found a mistake on the website?** Open a correction issue.
- **Made something?** A tree, a template, a translation, or a talk goes in "Show and tell."

See the Contributing page on the website for what makes a good report and how to anonymize a tree.
